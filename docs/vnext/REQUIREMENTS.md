# PaperScan vNext 要件

作成日: 2026-11-05
状態: ユーザー確定仕様を記録。実装・検証状態は [監査記録](AUDIT.md) と [検証・リリース計画](TEST_AND_RELEASE.md) を参照。

## 目的

既存PaperScanの撮影・補正・ページ管理・PDF保存・復元を維持しながら、書類検知、補正、連続撮影、多言語OCR、検索可能PDF、設定と表示品質を段階的に改善する。

## 確定機能

| 領域 | 要件 |
|---|---|
| 書類検知 | OpenCVを優先して改良する。候補の幾何形状と境界支持を評価し、信頼度の低い自動結果を確定しない。プレビュー中の検知枠、座標変換、撮影後再検知は実測を伴って導入する。手動四隅編集を維持する。 |
| 画像補正 | 射影変換、細かな傾き、照明ムラ・影、局所コントラスト、軽度ハイライト、ノイズを扱う。AUTO / TEXT / COLORを維持し、細線・数式・色を保護する。元画像は編集結果で上書きしない。 |
| 連続撮影 | 手動シャッターのみ。撮影後もカメラを表示し、ページ数と直近サムネイルを示す。二重保存を防ぎ、失敗を再試行でき、ページ一覧へ移動できる。 |
| ページ管理 | 追加、削除、並べ替え、個別編集を維持する。複数選択、全選択、選択解除、複数ページへの画質・補正一括適用、補正前後比較を追加する。手動四隅を一括操作で破棄しない。 |
| OCR | 日本語、英語、中国語（簡体字・繁体字）、韓国語。原則端末内・オフラインで処理し、画像を外部送信しない。自動認識を基本とし、必要なら言語指定を可能にする。テキスト、言語、ページ内位置を保持し、コピーと再試行に対応する。手書き、数式、複雑な表の精度限界を明記する。 |
| OCR状態 | 編集確定後に非同期認識する。画像または補正設定が変われば結果を無効化し、未変更ページは再利用する。ページごとの状態、キャンセル、再試行、競合防止、古い結果の適用防止を備える。PDF出力時に必要なページを認識する。 |
| PDF | 画像PDFと検索可能PDFを選べる。後者は補正後画像とUnicode文字レイヤーを同じページに置き、CJK検索・選択・コピー、位置整合、複数ページ、ビューア互換を検証する。OCR失敗時も画像PDFを作れる。 |
| 出力設定 | OCR初期値ON、画質（高画質／標準／軽量・初期値標準）、サイズ（自動／A4／A5／Letter）、方向（自動／手動）、色（自動／カラー／グレースケール／白黒）、SAF保存、セッション順を反映する。DPI・圧縮値は測定後に選ぶ。 |
| UI | Material 3、ライト／ダーク／システム（初期値）を提供し設定を保持する。ホーム、カメラ、ページ管理、編集、出力、完了の主要操作を実処理に接続する。装飾より可読性、カメラ画面の視認性、アクセシビリティを優先する。 |

## 維持する制約

- 既存の `applicationId`、`minSdk`、署名・ユーザーデータを変更しない。
- セッション形式を拡張する場合は、既存データを読み込む移行または後方互換処理を実装する。
- 画像・OCR・PDF処理はページ単位とし、UIスレッドで重い処理を行わない。
- OCR用画像や個人情報をログ、テスト資産、GitHubへ含めない。
- 自動シャッター、クラウドOCR、画像の完全復元を追加しない。
- 既存安定機能を守り、未完成機能を既存動作へ混入させない。

## 完了判定の原則

数値の精度・性能・容量は計測した値だけを記載する。エミュレータ、実機、単体テスト、PDFパーサーによる検証を区別し、未実施は `NOT RUN`、環境制約で実施不能は `BLOCKED` とする。
